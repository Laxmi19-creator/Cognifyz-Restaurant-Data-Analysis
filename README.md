# 🍽️ Restaurant Data Analysis using Python

## 📌 Project Overview

This project was completed as part of the **Data Analysis Internship at Cognifyz Technologies**.

The objective of this project is to analyze a restaurant dataset using Python, perform Exploratory Data Analysis (EDA), create visualizations, and derive meaningful business insights.

---

## 🎯 Objectives

- Perform data exploration and preprocessing
- Analyze restaurant ratings
- Analyze cuisines
- Study price ranges
- Analyze online delivery and table booking
- Explore restaurant chains
- Build predictive models
- Generate business insights using data visualization

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

# 📈 Key Insights

- Most restaurants belong to **Price Range 1**.
- Restaurants with **online delivery** attract more customer engagement.
- High-priced restaurants generally provide **table booking**.
- Most restaurant ratings fall between **3 and 4**.
